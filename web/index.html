Zig 101 — Everything You Need in 15 Minutes

          

            Written for Python, TypeScript, C#, and Rust engineers. Zig's core rule is simple:
            no hidden control flow, no hidden allocations, no macros.

2. Mutability, Slices & Loops

          
Use const by default and var only when mutating. Zig gives a compile error for unused variables or vars that are never mutated. Never compare slices with ==; use std.mem.eql(u8, a, b).

          
const port: u16 = 8080;
var count: usize = 0;
for (items, 0..) |item, i| {
    if (item == target) count += i;
}

        


        

          
3. Errors, defer & errdefer

          
Zig has no exceptions and no RAII destructors. Pair every allocation with defer (always runs on scope exit, LIFO) or errdefer (runs only if returning an error).

          
const scratch = try allocator.alloc(u8, 64);
defer allocator.free(scratch);

const result = try allocator.alloc(u8, 32);
errdefer allocator.free(result); // freed only on error!

        


        

          
4. Explicit Allocators & Leak Detection

          
Functions that allocate accept allocator: std.mem.Allocator. In tests, pass std.testing.allocator — it automatically fails the test if even 1 byte is leaked.

          
var list: std.ArrayList(i32) = .empty;
defer list.deinit(gpa);
try list.append(gpa, 42);

        


        

          
5. comptime & Io.Writer

          
Types are first-class values at comptime, so generic containers are functions returning type. In Zig 0.17, streaming output uses *std.Io.Writer and custom formatting uses pub fn format(self, w: *Io.Writer) with {f}.

          
fn RingBuffer(comptime T: type, comptime cap: usize) type {
    return struct { items: [cap]T = undefined, ... };
}
