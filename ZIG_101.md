# Zig 101 — Everything You Need to Know in 15 Minutes

*(Written for Python, TypeScript, C#, and Rust engineers targeting **Zig 0.17+**.)*

Zig's design philosophy is simple: **no hidden control flow, no hidden memory allocations, no preprocessor, no macros.** If a function can allocate memory, it takes an `Allocator`. If a function can fail, it returns `!T`. If something runs at compile time, it uses `comptime`.

Read this once (~15 mins), then run `zig build dojo` and work through **Katas 01–10**.

---

## 1. The "Weird Symbols" Decoder Ring

| Symbol | Example | What It Actually Means |
| :--- | :--- | :--- |
| **`.{ ... }`** | `.{ .host = "localhost", .port = 8080 }` | **Anonymous struct / tuple literal**. Types are inferred from context (like `std.debug.print("hi {s}\n", .{"zig"})`). |
| **`.name`** | `.running`, `.empty`, `.little` | **Inferred enum / decl literal**. Short for `Status.running`, `ArrayList(T).empty`, `Endian.little`. |
| **`[]const u8`** | `const name: []const u8 = "zig";` | **Read-only byte slice** (a pointer + length fat pointer). This is Zig's string type! |
| **`[]u8`** | `var buf: []u8` | **Mutable byte slice**. |
| **`[:0]const u8`** | `"hello"` (literal type is `*const [5:0]u8`) | **Sentinel-terminated slice**: guaranteed to have a `0` byte (`\0`) right after `len` (C-compatible!). |
| **`[*:0]const u8`** | `c_str: [*:0]const u8` | **Null-terminated C pointer** (unknown length, stops at `0`). Convert to a safe slice with `std.mem.span(c_str)`. |
| **`?T`** | `fn find() ?usize` | **Optional**: either a `T` or `null`. Normal pointers `*T` can NEVER be null; nullable pointers are `?*T`. |
| **`orelse`** | `const i = indexOf(s, ':') orelse return error.Bad;` | **Unwrap optional or fallback**: if `null`, evaluate the right-hand expression (which can `return` or `break`). |
| **`!T` / `E!T`** | `fn parse(s: []const u8) !u16` | **Error union**: either an error or `T`. `!T` infers the error set; `ParseError!T` names it explicitly. |
| **`try`** | `const n = try parse(s);` | **Propagate error**: if `err`, immediately `return err;` from the current function (like Rust's `?`). |
| **`catch`** | `parse(s) catch 80` or `catch \|err\| { ... }` | **Handle error**: unwrap value or run fallback / inspect `err`. |
| **`@builtin(...)`** | `@intCast(x)`, `@bitCast(b)`, `@This()` | **Compiler builtin** (replaces C macros and unsafe casts). |
| **`\|val\|`** | `if (opt) \|val\|`, `for (arr, 0..) \|x, i\|` | **Payload capture**: binds the unwrapped value or loop item (never a closure!). |

## 2. Variables, Mutability & Types

### `const` vs `var`
Use `const` by default; only use `var` if you reassign or mutate the binding:
```zig
const port: u16 = 8080;     // immutable
var count: usize = 0;       // mutable
count += 1;
```
**Important:** Zig gives a **compile error** for unused variables, unused function parameters, or `var`s that are never mutated. Discard intentionally with `_ = x;`.

### Explicit Integer Widths & `undefined`
- `u8`, `u16`, `u32`, `u64`, `i32`, `i64`, `usize` (pointer-sized unsigned, used for lengths/indices).
- `undefined` leaves stack memory uninitialized (for buffers you're about to fill, e.g. `var buf: [64]u8 = undefined;`).

### Strings Are Just `[]const u8`
Zig has **no `String` class**. String literals like `"hello"` coerce to `[]const u8`.
- **Never compare slices with `==`** (`a == b` compares pointer addresses? Actually it's a compile error!). Always use `std.mem.eql(u8, a, b)`.

## 3. Arrays, Slices & Loops

- **Array `[N]T`**: fixed size known at compile time, lives by value (`var a = [_]u8{ 1, 2, 3 };`).
- **Slice `[]const T` / `[]T`**: `{ ptr, len }` fat pointer into an array or heap buffer.
- **Slicing**: `buf[start..end]` (half-open `[start, end)`).

### `for` Loops
```zig
for (items) |item| { ... }                // values
for (items, 0..) |item, idx| { ... }      // values + index
for (0..10) |i| { ... }                   // range 0..9
for (&mut_items) |*item| { item.* += 1; } // mutable pointer to each element
```

## 4. Optionals (`?T`) & Error Unions (`!T`)

### Optionals (`?T`)
```zig
if (maybe_idx) |idx| {
    // `idx` is `usize` here
} else {
    // it was null
}

const idx = maybe_idx orelse 0; // default value
const must = maybe_idx.?;       // asserts non-null (panics in Debug/ReleaseSafe if null)
```

### Error Unions (`!T`)
Errors are lightweight enum-like values:
```zig
const ParseError = error{ EmptyInput, InvalidPort };

fn parsePort(s: []const u8) ParseError!u16 {
    if (s.len == 0) return error.EmptyInput;
    return std.fmt.parseInt(u16, s, 10) catch return error.InvalidPort;
}
```
Notice there are **no exceptions** and **no stack unwinding**. Every possible error path is visible right in the call site (`try` or `catch`).

## 5. `defer` & `errdefer` (Cleanup Without RAII)

Zig has **no destructors (`Drop`)**. Instead, you pair every acquisition with `defer` or `errdefer` right on the next line:

```zig
const tmp = try allocator.alloc(u8, 1024);
defer allocator.free(tmp); // runs ALWAYS when scope exits (LIFO order)

const out = try allocator.alloc(u8, 256);
errdefer allocator.free(out); // runs ONLY if this function returns an error!

try doFallibleWork(tmp, out);
return out; // `tmp` is freed, `out` is returned to caller
```

## 6. Structs, Enums & Tagged Unions

- **`struct`**: Data + methods. No inheritance, no interfaces.
  ```zig
  const Counter = struct {
      value: u32 = 0, // default field value
      pub fn inc(self: *Counter) void { self.value += 1; }
  };
  ```
- **`enum`**: Used with **exhaustive `switch`**:
  ```zig
  const status_text = switch (status) {
      .pending, .running => "active",
      .passed => "ok",
      .failed => "err",
  };
  ```
- **`union(enum)`**: Tagged union (sum type):
  ```zig
  const Event = union(enum) { start: u64, finish: bool };
  switch (ev) {
      .start => |ts| ...,
      .finish => |ok| ...,
  }
  ```

## 7. Memory & Allocators

In Zig, **nothing allocates behind your back**:
- Functions that allocate accept `allocator: std.mem.Allocator`.
- **`std.testing.allocator`**: Use this in `test` blocks! It tracks every allocation and **fails the test** if you leak even 1 byte.
- **`std.heap.ArenaAllocator`**: Great for request/frame-scoped scratch allocations — free everything at once with `defer arena.deinit();`.
- **Unmanaged Collections (Zig 0.15+)**:
  ```zig
  var list: std.ArrayList(i32) = .empty;
  defer list.deinit(gpa);
  try list.append(gpa, 42);
  ```

## 8. `comptime` & Generics

Zig doesn't need `<T>` generic syntax because **types (`type`) are values at `comptime`**:
```zig
fn RingBuffer(comptime T: type, comptime cap: usize) type {
    return struct {
        items: [cap]T = undefined,
        ...
    };
}
```
You can also inspect types at compile time with `@typeInfo(@TypeOf(x))` and unroll loops with `inline for`, generating zero-overhead specialized machine code.

---

## 9. `std.Io.Writer` & Formatting

Zig 0.17 uses `*std.Io.Writer` as its universal streaming writer:
- Stack buffer (zero heap allocs): `var fw: std.Io.Writer = .fixed(&buf);`
- Growable heap buffer: `var aw: std.Io.Writer.Allocating = .init(gpa); defer aw.deinit();`
- Custom struct formatting: implement `pub fn format(self: @This(), w: *std.Io.Writer) std.Io.Writer.Error!void` and format with `{f}`.

## 10. Binary Framing & C Interop

- **Endianness-safe wire integers**: `std.mem.readInt(u32, bytes[0..4], .little)` and `std.mem.writeInt(...)`.
- **Bit-exact structs**: `packed struct(u8) { ... }` + `@bitCast`.
- **C ABI**: `extern struct` + `export fn foo() callconv(.c)` + `[*:0]const u8` (`std.mem.span`).
